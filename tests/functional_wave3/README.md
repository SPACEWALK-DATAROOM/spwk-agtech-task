# Offline source module contracts

The loader compiles unchanged selected production definitions, skipping configured startup imports. Real pandas/NumPy, requests response parsing, JSON, gzip and local encoding conversions execute. External storage and HTTP boundaries are replaced; log sinks are logging.info. No business logic, model or service framework is reimplemented. The loader installs a network/DNS rejection audit hook.

The agriculture cases call only scalar/array normalization and reward arithmetic, synthetic weather-record processing and cache-key formatting. No gym/PCSE engine, model, weights, training or GPU is imported or invoked. Cache naming does not read/write home.

Run the new selection with the prepared Python3.9 de-ds-common-original-s3 environment:

```sh
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -c /dev/null --rootdir=. -q tests/functional_wave3
```

Only this new directory is selected. Prior tests, locks, fixes, wave1/wave2 and old150 artifacts remain unchanged and are not rerun. No production source changes, dependency installs or live service calls are included.
